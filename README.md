# Хөзрийн Танхим

Найзуудтайгаа онлайн **Блэкжек**, **13**, **Покер** тоглох сайт. Бүртгэл шаардахгүй: ширээ нээгээд холбоосоо явуулахад л хангалттай.

## Компьютер дээрээ ажиллуулах
1. [Node.js](https://nodejs.org) (18 буюу түүнээс дээш хувилбар) суулгана.
2. Энэ хавтсанд терминал нээгээд дараах тушаалуудыг ажиллуулна:
   ```
   npm install
   npm start
   ```
3. Хөтчөөрөө http://localhost:3000 хаягийг нээнэ.

## Интернэтэд байршуулах (Render.com, үнэгүй)
1. Энэ хавтсыг GitHub-д шинэ repository болгон хуулна.
2. https://render.com дээр бүртгүүлээд **New → Web Service** гэснийг сонгож, тэр repository-гоо холбоно.
3. Тохиргоо:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
4. **Deploy** дарвал `https://таны-нэр.onrender.com` хэлбэрийн хаяг гарна. Түүнийгээ найзууддаа явуул.

> Үнэгүй хувилбар 15 минут ашиглагдахгүй бол унтдаг. Дараа нь анх ороход 30–60 секунд ачаална.
> Ширээ, чипийн мэдээлэл серверийн санах ойд хадгалагддаг тул сервер дахин ачаалагдахад шинээр эхэлнэ.

## Онцлог
- Хөзрийг сервер тардаг. Тоглогч бүр зөвхөн өөрийн хөзрийг хардаг.
- 30 секунд хөдлөхгүй тоглогчийн өмнөөс автоматаар нүүдэл хийнэ (зогсох, өнжих эсвэл шалгах/хаях).
- Чат, чипийн жагсаалт, утсанд тохирсон дизайнтай.
- Зөвхөн чипээр тоглоно, жинхэнэ мөнгө байхгүй.
